# Img to ISO Convertor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a public, MIT-licensed repo with a one-argument script that turns a validated optical `.img` into a sibling `.iso`, with OS wrappers that install Python 3 if missing.

**Architecture:** Stdlib-only `img_to_iso.py` validates ISO9660 (`CD001` at PVD offset), copies to `{stem}.iso` beside the input, then re-validates. `run.bat` / `run.sh` ensure Python 3 then invoke the script. No pip dependencies; no secrets.

**Tech Stack:** Python 3.9+ stdlib (`pathlib`, `shutil`, `argparse`, `unittest`); Windows `run.bat` + `winget`; Unix `run.sh` + `apt`/`dnf`/`brew`.

**Spec:** [`docs/superpowers/specs/2026-09-09-img-to-iso-design.md`](../specs/2026-09-09-img-to-iso-design.md)

## Global Constraints

- Public repo: never commit secrets, private paths, credentials, or sample disk dumps
- `LICENSE` already exists (user-provided) — do not create, edit, or replace it
- Stdlib only — no `requirements.txt`, no pip packages
- Cross-platform: Windows + Linux + macOS
- Conversion mode: validate ISO9660 then copy/rename to `.iso`; if not ISO9660, fail with a clear message (do not rebuild raw disks)
- CLI: exactly one positional argument — input `.img` path; output = same directory, same stem, `.iso`
- Refuse overwrite if output already exists
- Wrappers: `run.bat` (Windows), `run.sh` (Unix) — auto-install Python 3 when missing
- Validate before and after copy (size + magic)
